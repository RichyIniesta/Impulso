# Impulso | Bradesco México

Base inicial del sitio web de Impulso, un espacio para comunicar la cultura, los avances, proyectos, valores y metas de Bradesco México.

## Estructura

```
.
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── assets/
    ├── icons/
    ├── images/
    └── logos/
```

## Desarrollo local

Abre `index.html` en un navegador o utiliza una extensión como Live Server en Visual Studio Code.

## Recursos visuales

- `assets/logos/`: logotipos y versiones autorizadas de marca.
- `assets/images/`: fotografías, banners e imágenes de proyectos.
- `assets/icons/`: favicon e iconografía del sitio.

Mantén los nombres de archivo simples y utiliza rutas relativas al incorporar recursos.

## Publicación

El proyecto puede publicarse mediante GitHub Pages desde **Settings → Pages**, seleccionando la rama `main` y la carpeta raíz (`/root`).

## Pendientes de contenido

Los indicadores, nombres de proyectos, metas y textos institucionales incluidos en esta primera versión son espacios de ejemplo y deben sustituirse por información validada antes de publicar.
